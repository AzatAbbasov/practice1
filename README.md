Расписание занятий

Приложение на Kotlin для ведения расписания.
В приложении можно выбрать день недели, ввести время и название предмета, а затем сохранить пару. Также любую добавленную пару можно удалить. Данные не пропадают после закрытия приложения, потому что сохраняются в память телефона с помощью SharedPreferences.

Сведения о сборке:
minSdk: 26 (Android 8.0)
targetSdk: 36
Язык разработки: Kotlin (XML-разметка, без Jetpack Compose)
